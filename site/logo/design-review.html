exSpace ロゴ 論点整理

v1〜v11 の迷走を止めるための整理です。新しいデザインはこの資料には含まれていません。

1. なぜ迷走したか

これまでの往復で出た要望を全部足すと、1つのマークに8つの仕事をさせようとしていました。

①方位磁針とわかる ②e が読める ③x が読める ④女性的・繊細・儚い ⑤尖らない ⑥シンプル ⑦小サイズで見える ⑧エクスペっぽい

このうち「①絵として方位磁針」と「②③文字として ex」は構造的に両立が難しいです。文字を立てると絵が消え(v9・v11)、絵を立てると文字が消える(v5・v10)。どちらかを直すたびに反対側が壊れる、モグラ叩きになっていました。責任は提案側(私)の設計にあります。1案ごとに最新のフィードバックだけに最適化して、全体の優先順位を決めずに進めたためです。

2. 世の中のロゴはどう解決しているか

強いブランドは、1つのマークに全部を入れず役割分担させています。

  • アプリアイコン:主役1つだけ(Instagram=カメラ。文字はない)
  • ロゴタイプ:ブランド名の文字組(「Instagram」の筆記体)。e や x を確実に読ませるのはここの仕事
  • ブランドの世界観:色・写真・言葉づかいで補強

つまり 決めるべきことは1つ:「アイコンの主役をどれにするか」。残りはロゴタイプと世界観に分担させれば、全要件は体系全体では満たせます。

3. 主役の選択肢(これまでの11案は実質この4路線)

A. 現行ロゴの正統進化

いまの exSpace ロゴ(コンパスローズ+X星)の骨格を保ち、要素を整理して磨く。実はまだ一度も試していない路線。

◎ エクスペっぽさが確実 / 方位磁針◎ / X も骨格に残る

△ 細部が多く最小サイズで潰れやすい→整理が腕の見せ所

B. 方位磁針の絵

文字盤+針+星(v10系)。ex はロゴタイプに任せる。

◎ 方位磁針が一目 / コンセプトも語れる

✕ アイコン単体では ex が読めない / 針の形の好みが決め手(雫はNG済み)

C. ex の文字

e+星x のモノグラム(v11系)。方位磁針は針先の暗示のみ。

◎ ブランド名が読める / 小サイズ最強

✕ 方位磁針の絵としては弱い(暗示どまり)

D. 情景・詩

針と光だけの抽象画(v8系)。説明せず雰囲気で語る。

◎ 儚さ・詩情は最強 / 差別化◎

✕ 方位磁針とも ex とも説明できない(v8→v10 で一度この理由で撤回済み)

4. すでに確定している資産(もう迷わない)

内容
合意済みコンセプト「あなたの『次』を指す針」/ x=星のきらめき / 配色=クリーム×チャコール×ラベンダー(+夜グラデの展開)
NG確定雫型の針 / 丸棒のx(針に見えない) / 片側だけの針(時計に見える) / 横棒が輪を貫通する e(θ・Øに見える) / 鋭い三角の針 / ブランドカラー無視の配色
保留中線の太さの基準(現行ロゴ=極細で儚い ⇔ Instagram=太くて明快。両方を参照として提示されており未決)

5. 次の一歩

決めるのは 「アイコンの主役」= A / B / C / D のどれか1つ。

あわせて線の太さの基準(繊細寄りか、明快寄りか)を決めれば、以後はその路線の中だけで磨きます。路線をまたぐ変更はもうしません。

私のおすすめは A(現行ロゴの正統進化)です。「エクスペっぽさ」の正体は現行ロゴの世界観そのものであり、唯一まだ試していない路線だからです。
